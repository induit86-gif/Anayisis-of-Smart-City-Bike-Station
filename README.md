# 🚲 Smart City Bike Sharing Data Analysis Using Power BI

## 📌 Project Overview

This project focuses on analyzing Smart City Bike Sharing Data using Microsoft Power BI. The objective is to transform raw bike-sharing data into meaningful insights that help understand station performance, revenue trends, usage efficiency, and operational patterns across different cities.

As part of my Data Analytics Module-End Assignment, I performed data cleaning, transformation, data modeling, DAX calculations, and interactive dashboard development to support data-driven decision-making in urban mobility management.

## 🎯 Project Objectives

- Analyze bike-sharing performance across different cities and stations.
- Identify cities with the highest and lowest revenue per kilometer.
- Understand revenue trends and changes over the years.
- Evaluate operational performance and cost efficiency.
- Identify underperforming cities and stations.
- Develop an interactive Power BI dashboard to support business decisions.

## 🔄 Project Workflow

### 1. Data Import & Exploration
- Imported the bike-sharing dataset into Power BI.
- Explored the dataset structure and identified important columns.
- Examined data types, missing values, and inconsistencies.

### 2. Data Cleaning & Transformation
Performed data preprocessing using Power Query Editor.

- Checked and removed duplicate records wherever appropriate.
- Handled missing and null values.
- Corrected data types and formatting issues.
- Renamed columns for better understanding.
- Transformed data into an analysis-ready format.

### 3. Data Modeling
Designed a logical data model to organize the dataset efficiently.

- Identified the fact table.
- Created relevant dimension tables.
- Established relationships between fact and dimension tables.
- Applied a Star Schema approach wherever appropriate.
- Reviewed relationship cardinality and cross-filter direction.

### 4. DAX Calculations

Used DAX to create calculated columns and measures for business analysis.

Key calculation areas:

- Total Revenue
- Total Cost
- Revenue per Kilometer
- Average Revenue
- City-wise Revenue
- Year-over-Year Revenue Growth
- Cost Efficiency

*Note: The final list of measures depends on the actual fields available in the dataset.*
